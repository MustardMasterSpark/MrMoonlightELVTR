MR. MOONLIGHT — DAY 1 SCRIPT
Grammar-corrected working draft with strict event annotations


STRICT FORMAT
EVENT ID | EVENT TYPE | CONTENT

EVENT TYPES
ACTION             Player-performed or world action.
SYSTEM             Gameplay-state change, trigger, restriction, or rule.
DIALOGUE:T         Spoken dialogue by Tracey. Audio and subtitles.
DIALOGUE:R         Spoken dialogue by Rylee. Audio and subtitles.
THOUGHT:T          Tracey's internal thought. On-screen text only.
ANIMATION          Character, first-person, prop, or camera animation.
CUTSCENE:BLOCKING  Temporarily removes or restricts player control.
VFX                Visual effect.
SFX                Sound effect or environmental audio cue.
MESSAGE            System, interaction, tutorial, or pickup message.
OBJECTIVE:START    Creates the current objective in the pause-menu form.
OBJECTIVE:UPDATE   Changes the current objective.
OBJECTIVE:END      Completes and removes the current objective.
BEAT               Pause, silence, staging, or timing instruction.
OUTLINE            Undetailed event retained from the unfinished outline.
NOTE               Production clarification that is not an in-game event.

SPEAKERS
T = Tracey
R = Rylee

OBJECTIVE UI
The current objective appears in the pause menu on a psychiatric-style form titled:
"How are you feeling today?" accompanied by a smiley face.
